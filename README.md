This is a circus game project



It is circus game project in which a clown moves horizontally holding 2 sticks and random colored shapes fall from above for the clown to collect.
When collecting three of the same color , the game points increase
The game has some additinal shapes for diffculty(bomb shaped , in which shapes stack fall out) or reward (time increase)
The game ends when the time assigned from the start ends
There are difficulty level in which the game speed increases , the reward shape number decreases and the bomb shape increases

To start the game run MainPage in Main package 

the packages in the project are : (listed according to functionality order)

1. Main : this is for the game front page intialization
2. circusgame : this is for the game backend intialization (for the game analogy itself)
3. DesignPatterns : this package is for the design patterns used to create the project in a S.O.L.I.D. (the five desgin ruled of OOP) environment
4. GameObject : this is or the game objects that the images/recources represent
5. resources : this package is for all the images used in the project
6. there is an engine (engine_v3) in the libraries,  that supports the backend implementation of the objects themseleves and how the work together
